# Translation review checklist (Kannada, Telugu, Hindi)

The Kannada, Telugu and Hindi text in `dashboard/i18n.js` is a first draft. It has not been reviewed by native
speakers. A reviewer should check each language against this list and record the result at the end.

1. **Meaning:** each entry says the same thing as the English entry with the same key, no more and no less.
2. **Honesty wording is kept exactly:** "not available", "scheduled, not live", "not an official app", "never takes a
   payment", "does not send alerts" must not be softened.
3. **Placeholders:** every `{name}` in the English text appears unchanged (for example `{date}`, `{number}`, `{version}`).
4. **Names stay recognisable:** BMTC, BMRCL, ONDC, NCMC, QR, SOS and 112 stay as written; "Namma Metro" uses the
   form commuters know in that language.
5. **Tone:** polite, plain and short enough for a phone screen; button labels fit on one line.
6. **Script and spelling:** correct conjuncts, vowel signs and punctuation; no mixed scripts except the names above.
7. **On screen:** open Home, Live tracking, Tickets and passes, Namma Metro, My account and More services in the
   language and check that nothing is cut off, at normal and at large text size.
