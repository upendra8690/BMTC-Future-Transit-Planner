# Data source and licence register

Checked 16 November 2026. Detailed research notes: `docs/4.0/DATA_SOURCE_REGISTER.md` and `SOURCES.md`.

| Data | Source | Licence / terms found | Status in the app |
|---|---|---|---|
| BMTC and BMRCL static GTFS | DULT Transport Data Hub (announced June 2024) | **Licence not found.** DULT's website copyright policy says its content may be republished only with prior permission | Not loaded; permission requested in the DULT letter |
| BMTC fares, Vajra timetable, Metro feeder service | BMTC website (PDF pages) | Website content; reuse needs BMTC's permission | Not used |
| Metro timetables and fares | BMRCL website | Website content; reuse needs BMRCL's permission | Not used |
| Community Metro GTFS (`Vonter/bmrcl-gtfs`) | GitHub | Built from OpenStreetMap (ODbL) and BMRCL timetable images; repository licence to be confirmed | Not used |
| Community BMTC GTFS (several) | GitHub, Kaggle | Derived from the official app or unofficial APIs | **Rejected** |
| Demo bus and Metro feeds | Generated by this project | Project's own; labelled SYNTHETIC | In use for demonstration |
| Map tiles | OpenStreetMap Foundation tile servers | Map data ODbL; attribution shown; tile usage policy limits heavy use | In use |
| Emergency numbers and official links | Government and operator websites, each opened on 16 Nov 2026 | Facts and links only | In use |

Rule applied: a dataset is shown only with a recorded source; official status requires a recorded licence and an
administrator's verification.
