# Third-party services register

| Service | Used for | Data it receives | Cost | Notes |
|---|---|---|---|---|
| Render (web hosting) | Running the app (3.0 live; 4.0 staging planned) | All requests incl. IP addresses | Free tier | Service region shown as Oregon (USA) in the dashboard; cross-border processing to be reviewed under DPDP |
| GitHub | Source code, CI, APK builds and releases | Source code; no user data | Free for public repositories | — |
| OpenStreetMap tile servers | Map images | Visitor IP and map area | Free, subject to the tile usage policy | Switch provider before heavy use |
| OpenStreetMap website | Walking directions links | Visitor IP and destination | Free | Opens in a new tab |
| Neon (planned) | Persistent Postgres for accounts | Account data | Free tier | Region to choose: Singapore (closest available) |
| Email provider (planned) | Password reset | Email address | Free tier | Not chosen |
| Official sites (BMTC, BMRCL, DULT, KIA, Indian Railways, ERSS, BTP, Karnataka Tourism) | Links only | Visit only | — | No data shared by the app |

No analytics, advertising, crash-reporting or AI services are used.
