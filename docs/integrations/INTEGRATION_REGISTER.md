## What "implemented" means here
The code exists and its automated tests pass, but only with test data, test doubles or a sandbox. None of it has been
connected to BMTC, BMRCL, ONDC, NPCI, a bank or a payment aggregator. Every unavailable item says so in the app, names
what is needed, and points to the official channel.
